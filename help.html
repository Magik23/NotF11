ANY BROWSER TAB, TOOLBAR-FREE.

Keep the page. Lose the browser clutter.

NotF11 moves the live Chromium tab you already have open into a clean desktop window, then lets the same tab return to a normal browser source.

Ctrl Shift F Clean ↔ normal

Getting started

Focus any ungrouped Chromium tab and press Ctrl Shift F. NotF11 moves that same live tab into a Clean popup-style window without reopening the page.

Same live tab. Scroll position, entered text, login/session state, navigation history and active web-app state can remain with the tab where Chromium permits.

Press the same shortcut again to return the tab to its normal browser source. Unlike F11 fullscreen, the Clean window remains a normal desktop window that can be moved, resized, maximized, snapped or tiled.

Settings

Clean on launch

Default: Off

Starts the first eligible browser surface in Clean mode when enabled. NotF11 checks that the main Toggle shortcut is actually assigned before allowing this feature to create an unsafe recovery situation.

New tabs stay clean

Default: Off

Controls only new tabs created from a Clean NotF11 workflow. With it off, the child stays Raw in the same source family. With it on, the child becomes another Clean window in that family.

Remember size & position

Default: On

When enabled, NotF11 asks Chromium to preserve the previous desktop footprint across Raw ↔ Clean transitions. Turn it off when you want a tiling window manager or compositor to own placement completely.

Keyboard shortcuts

Ctrl Shift FEnter or exit Clean mode
Ctrl Shift ,Previous eligible source tab
Ctrl Shift .Next eligible source tab

Previous and Next are not global browser-tab cycling. They hand the Clean role to another eligible Raw tab from the same remembered source family.

Browser shortcut conflicts are possible. Use Manage shortcuts in the NotF11 popup to review the commands Chromium actually assigned.

Source families

Clean changes the surface, not the family.

When a tab leaves a normal browser window and becomes Clean, NotF11 remembers the logical browser relationship it came from. 

Source family
├─ A → Clean
├─ B → Raw
└─ C → Raw

Previous / Next can hand the Clean role between eligible Raw members of that same family. If another browser window represents a different family, NotF11 does not cross into it.

Multiple Clean windows are supported. Family members that are already Clean are normally skipped during cycling because they already occupy their own Clean surfaces.

New tabs from a Clean window

New tabs created from a Clean workflow preserve family lineage.

New tabs stay clean = Off

A Clean
  └─ creates B

A remains Clean
B joins A's family as Raw

New tabs stay clean = On

A Clean
  └─ creates B

A remains Clean
B joins A's family as Clean

The setting changes the child's initial representation, not its ancestry. Ordinary Ctrl+T from a normal browser window remains ordinary Chromium behavior.

Recovery behavior

If the remembered source still exists

The same live tab returns to that normal browser source.

If the remembered source is gone

NotF11 creates a real normal replacement and moves the live tab there. It does not silently attach the tab to some unrelated browser window.

One-tab source

A normal browser window can naturally disappear when its only tab is moved Clean. If a new Raw tab is later created from that Clean workflow, the new tab can become the legitimate replacement source for that family.

After a browser restart

Chromium tab and window IDs are browser-session specific. If Chromium restores an old popup without a current NotF11 relationship record, NotF11 can recover it into a normal browser surface instead of guessing an old source relationship.

Window placement

Windows / ordinary desktop

Keep Remember size & position on when you want Raw ↔ Clean to preserve the previous desktop footprint where Chromium and the OS allow it.

This also works well with normal Windows snapping and tools such as PowerToys FancyZones.

Hyprland / tiling compositor

Turn Remember size & position off when the compositor should own placement, tiling, workspaces and scratchpad behavior.

NotF11 continues to own browser relationships, Raw / Clean representation and family handoff — not desktop topology.

NotF11 is not a window manager. Unexpected physical placement does not automatically mean the browser relationship is wrong.

Small, focused, and private

NotF11 does not inject scripts into websites and does not read or modify webpage content.

No analytics No telemetry No ads No tracking No account No cloud service No host permissions No content scripts

The extension uses its own local/session storage for settings and NotF11 relationship state. Window geometry may be used when Remember size & position is enabled.

Known behavior & limitations

  • The operating system's title bar remains visible intentionally.
  • Native Chromium tab groups are not currently supported.
  • Heavy web apps may briefly redraw while Chromium moves the live tab between windows.
  • Chromium or Windows can clamp requested geometry slightly at display edges.
  • Tiling window managers can visibly reflow when top-level browser windows appear or disappear.
  • Browser-reserved shortcuts or conflicts with other extensions can leave suggested shortcuts unassigned.
  • NotF11 does not choose Hyprland workspaces or control FancyZones.
